# 桌面壳排查记录

目标：双击一个程序 → 直接出现应用窗口，不经过浏览器标签页。

## 结论

- **已交付并验证可用**：桌面快捷方式 → `wscript` 跑 `ChatBox Pro.vbs` →
  后台拉起 8787 服务 → 用 **Edge 应用模式**（`--app=`）开一个无地址栏、无标签页的窗口。
- **Electron 方案已写好但本机跑不起来**：`electron.exe` 启动后立刻退出，
  退出码 `-2147483645`（`0x80000003`，STATUS_BREAKPOINT），不产生任何日志。

## 排查过的项

| 检查 | 结果 |
|---|---|
| `electron.exe` 二进制是否完整 | 完整（73 个文件，含 `icudtl.dat`、`vk_swiftshader.dll`） |
| 以 Node 模式运行（`ELECTRON_RUN_AS_NODE=1`） | 正常，能打印版本 |
| Electron 45 / 30 两个版本 | **都失败**，同样退出码 |
| `--no-sandbox --disable-gpu --in-process-gpu` 等组合 | 无效 |
| `ELECTRON_RUN_AS_NODE` 被宿主注入 | 已排除（bat 内 `set "ELECTRON_RUN_AS_NODE="` 清空后仍失败） |
| 经 `cmd start`、`explorer`、**计划任务** 启动（不同令牌） | 都失败 → 不是当前 shell 的受限令牌导致 |
| GUI 能力本身 | 正常（notepad 有窗口，Edge 能开窗） |
| 杀软 | 只有 Windows Defender，实时防护开启，无威胁记录 |
| 系统 | Windows 10 22H2（19045），VC++ 运行库齐全 |

## 判断

不是代码问题，是这台机器对**未签名的 Chromium 内核可执行文件**的限制
（疑似代码完整性守卫 / 安全策略一类，未开管理员权限去验证）。

## 影响与对策

- 用户在桌面双击快捷方式即可正常使用，**不受影响**。
- 如果以后想换回真正的 Electron 壳：先在一台干净的 Windows 上验证
  `npm run pack:desktop` 产出的 exe，再决定是否排查本机策略。
- 备查文件：`scripts/run-electron-diag.bat`（清空环境变量后启动 Electron 并把输出写进 `%TEMP%\el.log`）。
