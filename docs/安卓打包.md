# 安卓 App（ChatBox Pro）

手机上的原生安装包，**直连 DeepSeek，不依赖家里电脑**，在外面用 4G 也能用。

---

## 一、现成的安装包

```
F:\Apps\ChatBoxPro-Android\ChatBoxPro-1.0.2.apk
```

### 装到手机

**方法 1：数据线**

1. 手机用 USB 连电脑，选「传输文件」
2. 把上面的 APK 复制到手机（下载目录）
3. 手机上打开「文件管理」→ 点 APK → 允许「安装未知应用」

**方法 2：微信 / QQ 传给自己**

发送 APK 文件 → 手机上打开 → 安装（微信会提示"非官方应用"，选继续）

**方法 3：adb（电脑已装 platform-tools）**

```powershell
F:\AndroidDev\sdk\platform-tools\adb.exe devices          # 确认手机已连
F:\AndroidDev\sdk\platform-tools\adb.exe install -r "F:\Apps\ChatBoxPro-Android\ChatBoxPro-1.0.2.apk"
```

### 第一次打开

1. 填名字、选头像（和电脑端一样）
2. 设置 → 账号 → 填 DeepSeek API Key
3. 开始用

## 二、它是怎么工作的

```
手机 App（WebView 界面）
   │
   ├── 原生网络插件（ChatboxHttp）──────► https://api.deepseek.com
   │      · 绕开浏览器的跨域限制           · 流式返回（逐字显示）
   │      · multipart 上传文件解析
   │
   └── 本地存储（IndexedDB）
          · 会话、设置、API Key（加密）
```

和电脑端最大的区别：**电脑端走本地中转服务，手机端直连官方 API**。
所以手机上不需要电脑开着，也不需要连同一个 Wi-Fi。

## 四、开发者：怎么重新打包

### 环境（一次性）

```
JDK 21      F:\AndroidDev\jdk21
Android SDK F:\AndroidDev\sdk   （platform-tools / android-34 / build-tools 34.0.0）
Gradle 8.14.3 发行包  F:\AndroidDev\gradle-8.14.3-all.zip
```

`android/gradle.properties` 里已指定：

```properties
org.gradle.java.home=F:/AndroidDev/jdk21
```

`android/gradle/wrapper/gradle-wrapper.properties` 用的是**本地 Gradle 包**
（`file:///F:/AndroidDev/gradle-8.14.3-all.zip`），换机器时改成官方地址：

```properties
distributionUrl=https\://services.gradle.org/distributions/gradle-8.14.3-all.zip
```

`android/build.gradle` 里配了阿里云 / 腾讯云 maven 镜像，国内下载依赖更快。

### 命令

```powershell
npm run android:sync     # 构建前端 + 同步到 android/app/src/main/assets
npm run android:apk      # 打包出 debug APK

# 产物
android\app\build\outputs\apk\debug\app-debug.apk
```

### 原生代码在哪

| 文件 | 作用 |
|---|---|
| `android/app/src/main/java/com/chatboxpro/app/ChatboxHttpPlugin.java` | 直连插件：stream / json / upload / openExternal |
| `android/app/src/main/java/com/chatboxpro/app/MainActivity.java` | 注册插件 |
| `web/src/native.ts` | JS 侧封装：把插件事件变成 ReadableStream |
| `web/src/api.ts` | 原生分支（聊天、余额、文件、摘要） |
| `web/src/tools.ts` | 原生分支（搜索、抓网页；本地文件/命令返回不支持） |

## 五、正式发布（可选）

现在是 **debug 签名**，可以直接装，但：

- 不能上架应用商店
- 换签名后不能覆盖安装（要先卸载）

要自己生成正式签名：

```powershell
keytool -genkey -v -keystore chatboxpro.keystore -alias chatboxpro -keyalg RSA -keysize 2048 -validity 10000
```

然后在 `android/app/build.gradle` 里配 `signingConfigs`，再 `gradlew assembleRelease`。

> 这个签名文件**一定要备份**，丢了就没法给老用户推送更新。
