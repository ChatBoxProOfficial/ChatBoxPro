# 界面规格（v0.2）

> 记录用户口述的界面结构，改界面前先对齐这里。

## 主界面

- 顶部栏：左上角是**展开栏目**按钮（三横线），点开侧边栏；中间是标题（新会话时显示 ChatBox Pro）。
- 主体：**「您好，ChatBox Pro 欢迎您」**，下面一行小字（有什么可以帮你的？）。
- 首次发出消息后，主体切换成消息列表，欢迎语消失。

## 输入栏（从左到右）

1. **文件上传**：回形针图标，打开系统文件选择器，可多选；上传后在上方出现附件 chip（文件名、大小、移除）。
   文件落到服务器 inbox（桌面端是 `%APPDATA%\ChatBox Pro\inbox`）。
2. **收起 / 展开**：把输入栏收成更紧凑的一行。
3. 文本输入区（Enter 发送，Shift+Enter 换行）。
4. **模型名称**：显示当前模型（DeepSeek V3 / R1），点开可切换。
5. **发送按钮**：蓝色圆形，里面是向上箭头；发送中变停止按钮。

## 侧边栏（点左上角展开）

从上到下：

1. **Logo + 名称**：原子图标 + `ChatBox Pro`
2. **建立一个新的对话**
3. **对话列表**：每条显示标题、消息条数、时间；悬停出现删除；当前会话高亮
4. **底部账号**：圆形头像（显示名首字）+ 名称 + 「设置」，点击进入设置

## 设置（仿 DeepSeek 网页版「系统设置」弹窗）

点侧边栏底部账号行 → 弹出**居中的设置弹窗**（背景变暗），不是整页跳转。

```
┌───────────────────────────────────────────┐
│ 设置                                   ✕ │
├──────────────┬────────────────────────────┤
│ ● 账号与模型 │  右侧：当前分类的内容      │
│ ● 个性化     │                            │
│ ● 插件       │                            │
│ ● 管理模型   │                            │
│ ● 上下文管理 │                            │
│ ● 连接 DSH   │                            │
│ ● 保存路径   │                            │
│ ● 关于       │                            │
└──────────────┴────────────────────────────┘
```

- 左侧点分类，右侧直接切换内容，**没有二级页面**。
- 右上角 ✕ 或 Esc 关闭，回到刚才的对话。
- 窄屏（手机）自动变成：顶部横向滚动分类条 + 下方内容，弹窗铺满全屏。

| 分类 | 内容 |
|---|---|
| ChatBox Pro 账号与模型 | 显示名称、API Key（加密保存/更换/清除）、默认模型、温度 |
| 个性化 | 紧凑模式开关、系统提示词 |
| 插件 | 说明 + 暂无插件占位 |
| 管理模型 | 勾选启用哪些模型（至少一个）、添加/删除自定义模型 id |
| 上下文管理 | 每次携带最近多少条消息（0=全部）、删除本机全部会话 |
| 让 ChatBox Pro 连接到 DeepSeek Harness | 服务器地址、测试连接、接入后能力说明 |
| 管理模型保存路径 | 附件落地目录、复制路径、打开文件夹（仅桌面端） |
| 关于 ChatBox Pro | 版本、投喂作者入口 |

## 思维链展示（设置 → 管理模型）

设置项：**开启思维链展示**（开关式）+ **思考强度**（low / high / max）+ 两个风格单选。

| 选项 | 表现 |
|---|---|
| 1 号：仿 DeepSeek 网页版 | 折叠条「✦ 已深度思考（用时 3.2 秒）」，思考时自动展开，正文出现后自动收起，点开可回看 |
| 2 号：仿 DSH | 紧凑折叠块「• 思考过程 3.2s ›」，默认收起，展开是等宽小字、带边框、限高滚动 |
| 关闭 | 不渲染思维链，**同时向接口传 `thinking: {type: "disabled"}`**，省 token |

实现要点：
- 请求显式携带 `thinking: {type: enabled/disabled}` 与 `reasoning_effort`；
- 思维链与正文分开存（`Message.reasoning` / `reasoningMs`），不拼进正文；
- 同时识别 `delta.reasoning_content` 与 `delta.reasoning` 两种字段；
- 模型名已更新为 `deepseek-flash` / `deepseek-v4-pro`，旧名自动迁移。

## 设置里的控件形态

所有“开/关”类设置统一用**开关（switch）**，不用勾选框；二选一的风格用单选卡片。
